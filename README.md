# Data-Analytics-Dashboard
<img width="390" height="280" alt="image" src="https://github.com/user-attachments/assets/1e3723db-c549-4d6b-97ce-d4fe3fcf4240" />

GreenLeaf Project, launched in 2024, is an eco-friendly e-commerce platform offering reusable and non-toxic home goods. Despite rapid growth, poor data standards hindered decision-making. The project is addressed by cleaning data, defining KPIs &amp; building dashboards, enabling GreenLeaf to drive sustainable growth and strengthen market leadership.
